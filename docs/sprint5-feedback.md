# Sprint 5: feedback met een klasgenoot

Dit is een invulformulier. Er is nog geen peer review uitgevoerd en er zijn
nog geen namen of opmerkingen ingevuld. Gebruik alleen feedback die echt is gegeven.

## Feedback ontvangen

- Reviewer: nog invullen
- Datum: nog invullen
- Bekeken commit of GitHub-link: nog invullen

Laat de reviewer de API starten via de README en vraag om deze controles:

- [ ] Kun je zonder hulp vinden waar spelers-endpoints staan?
- [ ] Kun je uitleggen welke code in routers, services en repositories hoort?
- [ ] Zijn database models en Pydantic schemas duidelijk van elkaar gescheiden?
- [ ] Werken speler aanmaken, ophalen, wijzigen en verwijderen?
- [ ] Werken scores toevoegen, scorelijsten en het leaderboard?
- [ ] Geeft de API begrijpelijke fouten bij verkeerde invoer?
- [ ] Blijven wijzigingen na een serverherstart behouden?
- [ ] Is duidelijk hoe je een nieuw endpoint zou toevoegen?

| Ontvangen opmerking | Concreet voorbeeld/bestand | Mijn actie en resultaat |
| --- | --- | --- |
| Nog invullen | Nog invullen | Nog invullen |

Beschrijf ook wat je bewust niet overneemt en waarom. Voer bij codewijzigingen
de tests opnieuw uit en commit de verbeteringen met een duidelijke boodschap.

| Onderdeel | Mijn waarneming | Mijn feedback |
| --- | --- | --- |

makkelijk/moeilijk. Je kunt ... aanpassen omdat ...". Vul de inhoud aan met
eigen bevindingen; dit is geen al gegeven feedback.
